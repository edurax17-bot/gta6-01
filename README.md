Solmar City — Harbor Heist: an original open-world crime game in the spirit of GTA 6. Lena "Vex" Marlowe owes the Harbor Crew $12,000. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the Solmar PD through a five-star wanted system, fight the Rust Vipers, and finish six story jobs to clear the debt.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — the game is plain static files under `game/`.

## How to play

- **WASD / arrows** — walk and drive, **SHIFT** — run
- **E** — steal / enter a car, exit a car
- **Mouse** — aim, **Click** — shoot
- **M** — mute, **P** — pause (S saves, R restarts the job, Q quits to menu)

Six story missions, traffic and pedestrians, police cars and foot cops, a live minimap, a day/night cycle, autosave after every job, and free roam once the story is done. Solmar City, its characters, vehicles, names and story are all original.
